# 站点发布工作流

## 一次完整发布的顺序

1. 在个人资料库工作区中完成内容更新
2. 构建最新站点
3. 用本仓库同步该版本站点
4. 运行审计脚本
5. 生成 `robots.txt / sitemap.xml / 404.html`
6. 用本地静态服务器模拟检查
7. 上传到阿里云 `OSS`
8. 刷新 `CDN`
9. 做公网抽样验收

## 推荐命名

- 版本归档：`site/v0.1.0`
- 当前准备上线版本：`site/current`

## 每次发布至少检查

- 首页
- 关于页
- 作曲家目录页
- 指挥目录页
- 搜索页
- 至少一条录音页
- 样式和图片资源
- 404 页面

## 禁止事项

- 不要把桌面应用源码放进这个仓库
- 不要把构建缓存和临时目录放进这个仓库
- 不要把本地磁盘路径暴露到公网站点
- 不要把测试专栏和测试链接一起带上线
